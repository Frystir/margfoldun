# 🔢 Margföldunartaflan

Einföld og skemmtileg vefforrit til að hjálpa ungum nemendum að læra margföldunartöfluna.

## 🚀 Lifandi útgáfa

Hægt er að setja upp á **GitHub Pages** – sjá leiðbeiningar hér að neðan.

## ✨ Eiginleikar

- 🎯 **Æfingastilling** – spurningar um valda töflu (1–10) með strax-endurgjöf
- 📊 **Töfluyfirlit** – sýnir alla útkomuna í einni töflu
- 🔥 **Runa-teljari** – eldur ef þú ert lengi í röð
- 🎉 **Konfettí** – sprengur þegar þú nærð 3+ í röð
- 📈 **Tölfræði** – rétt/rangt og nákvæmniprósentna
- 📱 **Virkar á síma og tölvu**

## 📁 Skrár

```
margfoldunartafla.html   ← allt forritið í einni skrá
README.md
```

## 🖥️ Hvernig á að nota

### Beint í vafra
Opnaðu `margfoldunartafla.html` beint í vafra – engin uppsetning þarf.

### GitHub Pages
1. Búðu til nýtt repository á GitHub
2. Settu upp báðar skrárnar (`margfoldunartafla.html` og `README.md`)
3. Farðu í **Settings → Pages**
4. Veldu branch `main` og möppuna `/root`
5. Smelltu **Save** – síðan er tilbúin á nokkrum mínútum

> 💡 Til að `index.html` virki beint á slóðinni (t.d. `https://notandi.github.io/repo/`) skaltu endurnefna `margfoldunartafla.html` yfir í **`index.html`** áður en þú hleður upp.

## 🛠️ Tækni

- Hreint HTML/CSS/JavaScript – engin framework eða pakkar
- Google Fonts (Fredoka One + Nunito) – þarf nettsamband í fyrsta skipti
- Virkar alveg án nettsamband eftir fyrstu hleðslu (þ.e. ef leturgerðirnar eru í skyndiminni)
